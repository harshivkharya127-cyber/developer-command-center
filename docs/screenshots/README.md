save them here with these exact names so the README images resolve:

| File | What to capture | Tips |
| --- | --- | --- |

| `contributions-dark.png` | Heatmap section of `/` | Toggle dark mode first |
| `tasks.png` | `/tasks` with a few tasks, one overdue | Shows badges + due dates |
| `pull-requests.png` | `/pull-requests` | — |

shots use the theme toggle (sun/moon icon) in the sidebar.
